## 서비스 소개

Rallit은 내 조건에 맞는 테니스 매치를 찾고, 코트를 확보한 사용자와 함께 경기할 참가자를 연결하는 모바일 웹 서비스입니다.

실력과 희망 일정에 맞는 매치를 추천받아 참가하거나, 확보한 코트를 등록해 직접 참여할 매치를 개설할 수 있습니다.

<br />

## 주요 기능

현재 초기 개발 단계이며, 아래는 **MVP 기준 구현 예정 기능**입니다.

| 기능                | 설명                                     |
| ------------------- | ---------------------------------------- |
| 회원가입, 프로필    | 회원가입, 테니스 실력 및 경기 조건 설정  |
| 매치 추천, 참가     | 조건에 맞는 매치 추천, 참가 신청 및 취소 |
| 코트 인증, 매치 개설 | 코트 예약 증빙 제출, 매치 개설 및 관리   |
| 입금, 참가 확정     | 수동 입금 확인, 참가 및 매치 확정        |
| 경기 완료, 참여 이력 | 경기 완료 처리, 참여 이력 저장 및 조회   |
| 알림                | 신청 상태, 매치 변경, 경기 리마인드 안내 |
| 운영자 관리         | 코트 검수, 매치, 입금, 환불, 정산 관리   |
